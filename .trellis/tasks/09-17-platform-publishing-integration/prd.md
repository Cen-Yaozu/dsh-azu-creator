# B站与视频号真实账号及发布接入

## 目标

用户在 Azu 桌面端连接自己的真实 B 站、视频号账号，从现有内容中选择视频与封面，检查提交信息并确认投稿；系统读取平台返回的作品标识、处理状态和可用链接。发布结果按内容和账号保存，刷新、重启后可继续查看。

实施顺序为 B 站 → 视频号。B 站链路验收通过后，再使用共同的账号与任务能力接入视频号。

## 用户流程

### 1. 连接真实账号

从“内容 → 账号管理”登记 B 站或视频号账号，点击“连接平台”，完成扫码及必要的手机确认。系统实际读取平台账号身份，再将平台唯一账号标识绑定到本地账号。

登录失败、二维码过期、用户取消、需要额外验证或身份与原绑定不一致时，给出明确状态与操作入口。不能因凭据文件存在或浏览器被打开而显示“已连接”。一个本地账号只绑定一个确定的平台身份；同平台多账号相互隔离。

### 2. 检查内容并投稿

从内容详情选择已连接的目标账号、视频、可选封面，填写标题、简介、标签及平台必填信息。B 站包括投稿分区，以及接口要求的原创/转载信息；视频号包括实际需要的短标题等字段。

先展示确定的账号、素材与投稿参数，再由用户确认提交。支持的视频号草稿操作应标明“上传到平台草稿”，与正式发表分开。没有草稿能力的平台不显示虚假的草稿按钮。

确认后生成持久化任务，展示进度与错误。界面关闭不应丢失任务记录；重启后不得因为上次状态不明而自动重复投稿。

### 3. 回读真实结果

系统区分上传中、已提交、审核中、已发布、审核未通过、执行失败和结果待确认。只有平台可核验的回读证据满足条件时，才显示“已发布”。B 站上传结束和审核通过分别记录。

在内容详情与概览查看对应账号的作品标识、链接、状态和最近核验时间。平台未返回公开链接时如实显示，不拼接无法验证的地址。手动登记与平台回读使用不同来源标识，不把旧手动记录升级为已核验结果。

## 范围

| 范围内 | 本轮不做 |
|---|---|
| B 站、视频号真实登录与账号身份绑定 | 抖音、小红书等其他平台 |
| 本机独立运行时与多账号登录态隔离 | 独立内容管理网站或替换 Azu 界面 |
| 视频素材选择、校验与单账号投稿任务 | 跨账号一键批量投稿 |
| 视频号草稿、两平台确认后的正式投稿 | 定时投稿、自动选题或自动生成素材 |
| 平台作品标识、审核/发表状态、链接回读 | 播放量趋势、收益和评论运营 |
| 任务持久化、冲突防护、取消及重启恢复 | 自动绕过验证码或自动重试未知提交 |
| 保留手动登记及已有制作工具 | 重写整个旧发布子系统 |

## 验收标准

### 公共能力

- [ ] 每个平台的能力来自已实现适配器，未支持的操作不显示为可用。
- [ ] 登录态不进入 Git、普通账号 JSON、浏览器响应或业务日志；账号记录仅保存私有凭据引用及身份信息。
- [ ] 两个同平台账号各自登录与检查，操作始终指向预览中确认的账号。
- [ ] 输入变更、账号变更或素材变更使旧提交确认失效。
- [ ] 同一账号的登录/发布任务相互排斥；重复点击不生成重复投稿。
- [ ] 未知提交结果只能进入查询核验，不能自动重新提交。
- [ ] 任务与结果在刷新、关闭窗口及服务重启后保留；可取消的任务能释放本机资源。
- [ ] 旧本地账号、手动记录与内容文件保留；迁移可回滚，历史结果无重复计数。

### B 站

- [ ] 在 macOS Apple Silicon 上启动依赖并检查固定版本。
- [ ] 用户扫码后实际读取账号唯一标识与昵称；登录过期可重新连接，账号变化需重新确认绑定。
- [ ] 使用用户明确指定的一条视频和账号完成投稿，回读平台接受投稿的证据及稿件标识。
- [ ] 可区分审核中、已发布和审核未通过；有有效公开链接时能打开正确作品。
- [ ] 超时/断网等异常中不误报已发布，不发生无依据的重复投稿。

### 视频号

- [ ] 扫码、二维码过期、手机确认及取消流程可用，完成后回读真实身份。
- [ ] 一条用户指定视频可保存为平台草稿，并核验草稿实际存在。
- [ ] 用户确认正式发表后，可在平台作品记录中匹配到对应内容及状态。
- [ ] 不仅依赖页面跳转、按钮消失或进程退出码判断发表成功。
- [ ] 平台不提供公开链接或状态存在歧义时，保留证据并显示结果待确认。

### 交付

- [ ] 相关单元测试、适配契约测试、类型检查和构建通过。
- [ ] 本地安装、服务启动、桌面交互、真实登录、真实投稿与平台回读分别留证。
- [ ] 验收记录标出每个平台的已验证能力、未验证项、版本与时间；没有真实素材或扫码时，不将任务标为完成。
