# 本地内容管理

在“内容”工作台可以完成以下流程，无需安装发布脚本：

1. 点击“新建内容”，填写主题，选择从母内容或视频稿开始。
2. 在内容详情编辑正文，选择草稿、待审阅或已就绪，点击“保存稿件”。各渠道稿件分别保存。
3. 返回概览，打开“账号管理”，登记平台、账号名称、主页链接和备注。同一平台可以登记多个账号；普通登记显示“已登记 · 未连接平台”；B站可进一步扫码连接，见 [B站账号连接](bilibili-connection.md)。
4. 回到内容详情，在“目标账号与发布记录”中勾选账号，保存投放目标。
5. 手动发布后，逐账号登记发布链接和时间，再保存记录。返回概览可看到已发布记录与待发布账号数量。

账号可编辑、停用。停用后不允许新增投放目标，原有记录仍可查看和维护。移除已有发布结果的目标前，需先将其改为待发布。已归档内容只读。

保存发生冲突时，页面保留输入并提示重新读取；不要直接覆盖其他窗口的修改。离开尚未保存的稿件时会提示确认。

## 数据与边界

稿件使用现有 Creator 内容目录及项目修订号。账号与逐账号发布记录保存在有效 `dataDir` 下的 `content-accounts.json`，采用写锁、修订号检查与原子替换，重启后保留。

只保存账号名称、主页、备注、启用状态和手动发布结果，本地登记文件不保存平台密码、Cookie 或令牌。B站连接的凭据另存私有目录，见 B站连接文档。已发布表示用户手动登记，并不等于平台核验。后台不会因登记记录而上传或发布。

同一内容在不同账号下分别记录状态。原有按平台汇总的历史发布事实仍保留，概览同时统计这两类记录；同一真实发布若在两处重复登记，会计作两条记录。

“高级制作与自动发布”保留原有制作、平台连接及自动发布工具，其外部运行依赖独立配置。
